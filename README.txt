EDITABLE PORTFOLIO WEBSITE

Files:
- index.html: page structure and portfolio content
- style.css: design, colors, layout, and responsive styles
- script.js: edit mode, browser saving, reset, and mobile navigation

HOW TO USE
1. Extract the ZIP file.
2. Open index.html in a browser (Chrome, Edge, Firefox).
3. Click "Edit website".
4. Click any highlighted text and replace it with your own information.
5. Click "Save changes". Your edits are saved in that browser on that device.
6. To change colors or spacing, edit style.css in a code editor such as VS Code.
7. To change the page layout or add sections, edit index.html.

NOTES
- This starter uses sample content. Replace the name, bio, projects, skills, links, email, and initials.
- The profile image area is a styled placeholder. To use your own photo, replace the .portrait-placeholder element in index.html with an img element and style it in style.css.
- Browser-saved edits are local to the browser/device. They are not automatically published online.
- To publish the site, upload the extracted files to a static hosting service.
